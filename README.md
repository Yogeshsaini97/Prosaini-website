# Pro Saini website

The first phase of the Pro Saini website is a responsive React/Vite hero page with a video carousel and navigation shell.

## Run locally

```sh
npm install
npm run dev
```

The supplied background videos are in `public/assets`. The hero rotates through four project themes and advances through the video clips. Use the arrow buttons to move between themes, or pause automatic rotation on desktop.

The navigation and project links are placeholders for the next website phases.
